# ארץ עיר אונליין

משחק ארץ עיר מרובה משתתפים, בעברית ובאנגלית. פותחים חדר, שולחים קישור בוואטסאפ, ומשחקים מהנייד או מהמחשב. בלי הרשמה ובלי הורדות.

**באוויר:** https://eretz-ir.joni0000.workers.dev

* **שתי שפות:**
  * **ממשק:** כל שחקן בוחר לעצמו עברית או English, בכפתור למעלה.
  * **משחק:** המארח בוחר את שפת המשחק. באנגלית יש קטגוריות באנגלית ואותיות A-Z. Q, U, V, X, Y, Z כבויות כברירת מחדל, ואפשר להדליק אותן.
* **פריסה אוטומטית:** כל push שמשנה את `eretz-ir/` מריץ בדיקות ופורס ל-Cloudflare Workers, דרך `.github/workflows/eretz-ir.yml`. הפריסה משתמשת באותו `CLOUDFLARE_API_TOKEN` שכבר מוגדר לריפו. כל חדר רץ ב-Durable Object משלו.

* **אותו מנוע בשני מקומות:** `room.mjs` מחזיק את כל החוקים. הוא רץ ב-Cloudflare (`worker.mjs`) וגם בשרת Node עצמאי (`server.mjs`, בלי חבילות ובלי מסד נתונים).
* **עדכונים חיים:** Server-Sent Events. עובד דרך כל פרוקסי ורשת סלולרית.
* **חוזרים למשחק אחרי רענון או ניתוק:** הדפדפן זוכר את השחקן, והתשובות נשמרות בשרת תוך כדי הקלדה.

## הרצה מקומית

```bash
cd eretz-ir
node server.mjs
```

פותחים http://localhost:3000. בדיקות: `npm test`. גרסת Cloudflare מקומית: `npx wrangler dev`.

## העלאה לשרת משלכם (חלופה ל-Cloudflare)

### אפשרות א: Docker

```bash
cd eretz-ir
docker build -t eretz-ir .
docker run -d --name eretz-ir --restart unless-stopped -p 3000:3000 eretz-ir
```

### אפשרות ב: Node ישירות עם systemd

```bash
sudo cp -r eretz-ir /opt/eretz-ir
sudo tee /etc/systemd/system/eretz-ir.service >/dev/null <<'UNIT'
[Unit]
Description=Eretz Ir online
After=network.target
[Service]
WorkingDirectory=/opt/eretz-ir
ExecStart=/usr/bin/node server.mjs
Environment=PORT=3000 NODE_ENV=production
Restart=always
User=www-data
[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now eretz-ir
```

### nginx לפני השרת (מומלץ, בשביל HTTPS ודומיין)

ההגדרות של `/api/events` חשובות: בלי `proxy_buffering off` העדכונים החיים יתקעו.

```nginx
server {
  server_name eretz.example.com;
  location /api/events {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Connection '';
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 1h;
  }
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
  }
}
```

אחר כך `sudo certbot --nginx -d eretz.example.com` בשביל HTTPS. Caddy עובד גם בלי הגדרות מיוחדות: `eretz.example.com { reverse_proxy 127.0.0.1:3000 }`.

## מגבלות שכדאי לדעת

* **המצב נשמר בזיכרון:** פריסה חדשה, או הפעלה מחדש של שרת ה-Node, סוגרת את החדרים הפתוחים. ב-Cloudflare חדר נמחק כשאף שחקן לא מחובר אליו. בשרת Node הוא נמחק אחרי 45 דקות.
* **שרת Node הוא תהליך אחד:** אל תריצו כמה עותקים מאחורי load balancer. שרת אחד מחזיק בנוחות מאות שחקנים במקביל.
* **אין בדיקת מילון:** האתר בודק רק את האות הראשונה. האם "בננה" היא באמת צומח, השחקנים מחליטים בהצבעה, כמו בשולחן.
