# קוד היום · CodeHayom

אתר קופונים לאליאקספרס בעברית, לקונים מישראל. האתר מתעדכן לבד כל 3 שעות, וכל לחיצה על קופון עוברת דרך קישור השותפים שלכם.

## השם והדומיין: קוד היום, `codehayom.com`

| | |
|---|---|
| **למה "קוד היום"** | ביטוי עברי יומיומי שעובר את "מבחן הרדיו": מי ששומע אותו פעם אחת יודע לאיית אותו. הוא אומר בדיוק מה האתר נותן (קוד) ולמה כדאי לחזור (היום). |
| **בלי סיכון סימן מסחרי** | סעיף 8.3 בהסכם תוכנית השותפים של אליאקספרס אוסר לרשום דומיינים "זהים או דומים" לסימנים שלה. שם בלי "Ali" לא מסכן את חשבון השותפים, כלומר את ההכנסה. |
| **בולט מול המתחרים** | כמעט כל המתחרים נקראים "קופון משהו" (hacoupon, couponexpress, israelcoupon, freecoupon, coupon-code...). "קוד" כמעט לא תפוס כמותג. |
| **SEO** | לגוגל אין בונוס לדומיין עם מילת מפתח (Exact Match Domain), כך שהשם לא חייב להכיל "אליאקספרס". את מילות המפתח, בכל האיותים (אליאקספרס, אלי אקספרס, עלי אקספרס), שמים בכותרות ובתוכן. |
| **למה לא "אליקוד"** | alikod.com כבר פעיל: זה אתר קודי אליאקספרס מתחרה, שנרשם ביולי 2026. בנוסף, השם מסכן את חשבון השותפים ונשמע כמו "עלי-קוד" או "ליכוד". |
| **מה פנוי (נבדק 5.11.2026)** | `codehayom.com`, `kodhayom.com` |

**מה לקנות (Spaceship):** `codehayom.com` כדומיין הראשי ("code" באנגלית, כמו שכולם מקלידים), ובנוסף `kodhayom.com` עם הפניה לראשי. הבדיקה נעשתה דרך RDAP של Verisign.

## איך זה עובד

```
מקורות נתונים                    בנייה (כל 3 שעות ב-GitHub Actions)            האתר
data/coupons.json (ידני)   ┐
Google Sheet (CSV)         ├─► scripts/fetch.mjs → data/generated.json  ┐
AliExpress Affiliate API   │   (מוצרים בשקלים לישראל + לינקי שותפים)    ├─► scripts/build.mjs → dist/ → GitHub Pages
r/AliExpressCode (Reddit)  ┘   (קודים מהקהילה, מסומנים "לא נבדק")      ┘
```

* **חשיפת קוד:** לחיצה על "הצג קוד" מעתיקה את הקוד ופותחת את אליאקספרס בלשונית חדשה דרך `/go/<id>/`, הקישור שלכם. אחר כך מופיע חלון עם הקוד וההוראות. ההודעות בחלון משקפות מה באמת קרה: אם ההעתקה או הלשונית נחסמו, החלון אומר את זה.
* **תוקף:** קוד שפג תוקפו יורד מהרשימה בבנייה הבאה. הוא מוסתר גם בדפדפן, כך שגם אם בנייה נכשלה לא יוצג קוד שפג תוקפו.
* **אמינות:**
  * "נבדק" מופיע רק על קוד שהזנתם לו תאריך `verified`.
  * תאריך "עודכן" זז רק כשהנתונים באמת השתנו.
  * קודים מהקהילה מסומנים "לא נבדק".
* **הגנה מנתונים שגויים:**
  * רק קישורי `https` לדומיינים של אליאקספרס יכולים לצאת מהאתר. קישור אחר מוחלף בקישור השותפים הכללי.
  * תאריך לא תקין מדלג על הקוד ומדפיס אזהרה, והבנייה לא נשברת.
  * תאריכים בפורמט ישראלי (`30/11/2026`) נתמכים.
* **בלי נתוני דוגמה באוויר:** ב-CI מוגדר `BUILD_STRICT=1`. כל עוד יש רק קודים לדוגמה, או שקישור השותפים הוא placeholder, הבנייה נכשלת ושום דבר לא עולה. בתצוגה מקומית יופיע פס צהוב "תצוגה מקדימה", והעמודים מסומנים noindex.

## עמודים

| נתיב | מטרה |
|---|---|
| `/` | "קוד קופון אליאקספרס [חודש שנה]": קודים, טבלת מדרגות, שאלות נפוצות, דילים |
| `/deals/<קטגוריה>/` | 8 קטגוריות. כל עוד אין בהן מוצרים הן מסומנות noindex ולא נכנסות ל-sitemap |
| `/sale/11-11/`, `/sale/black-friday/`, `/sale/anniversary/` | עמודי מבצע שקיימים כל השנה וצוברים סמכות, עם ספירה לאחור |
| `/guides/...` | 5 מדריכים לחיפושי זנב ארוך |

**SEO:**
* בכל עמוד: canonical, Open Graph, ונתונים מובנים מסוג BreadcrumbList, FAQPage ו-Article.
* ב-`sitemap.xml` תאריך `lastmod` מתעדכן רק כשהתוכן באמת השתנה.
* `robots.txt` חוסם את `/go/`.
* כל קישורי השותפים מסומנים `rel="nofollow sponsored"`.

## הפעלה, צעד אחר צעד

1. **קישור שותפים:** ב-[AliExpress Portals](https://portals.aliexpress.com) יוצרים קישור כללי (`https://s.click.aliexpress.com/e/...`) ושמים אותו ב-`config/site.json` תחת `affiliate.defaultLink`.
2. **קודים:** מעדכנים את `data/coupons.json` עם קודים אמיתיים, מוחקים את `"sample": true` ומעדכנים את `updated`. אפשר גם לנהל את הקודים בגוגל שיטס (שלב 4).
3. **GitHub Pages:** ב-Settings ← Pages בוחרים Source: **GitHub Actions**. אחר כך ממזגים ל-`main`.
4. **סודות** (Settings ← Secrets ← Actions):

   | Secret | מה זה נותן |
   |---|---|
   | `ALI_APP_KEY`, `ALI_APP_SECRET`, `ALI_TRACKING_ID` | מ-[AliExpress Open Platform](https://openservice.aliexpress.com): דילים בשקלים עם משלוח לישראל, ולינקי שותפים שנוצרים אוטומטית. מומלץ לבצע קריאת בדיקה אחת אחרי ההגדרה. |
   | `COUPONS_SHEET_CSV_URL` | בגוגל שיטס: קובץ ← שיתוף ← פרסום באינטרנט ← CSV. העמודות מופיעות ב-`data/sheet-template.csv`. כל שורה עם `id` קיים דורסת רק את השדות שמולאו בה. |
   | `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`, `REDDIT_USERNAME` | אפליקציה מסוג script ב-[reddit.com/prefs/apps](https://www.reddit.com/prefs/apps). שימו לב: לפי תנאי ה-Data API של Reddit, שימוש מסחרי דורש אישור מהם. בלי המפתחות האלה המקור פשוט מדולג. |

5. **דומיין:**
   * ב-Settings ← Pages ← Custom domain מזינים `codehayom.com` ומסמנים Enforce HTTPS.
   * אצל הרשם מגדירים 4 רשומות **A** לדומיין עצמו: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
   * מגדירים רשומת **CNAME** ל-`www` שמפנה ל-`<user>.github.io`.
6. **אנליטיקס:** שמים את מזהה GA4 ב-`analytics.ga4Id`. האירועים `coupon_reveal`, `outbound_click` ו-`product_click` נשלחים אוטומטית.
7. **Google Search Console:** מאמתים את הדומיין ומגישים את `https://codehayom.com/sitemap.xml`.

## פיתוח מקומי

```bash
cp .env.example .env   # אופציונלי
npm run fetch          # משיכת נתונים
npm run dev            # בנייה + שרת על http://localhost:8080
npm test               # 11 בדיקות: תאריכים, מיזוג, קישורים בטוחים, CSV, חתימת API
```

אין תלויות. מספיק Node 20 ומעלה.

## אוטומציה ותחזוקה

* **בנייה כל 3 שעות.** אם מקור נתונים נופל, האתר ממשיך להציג את הנתונים מהבנייה הקודמת, שנשמרים ב-cache של Actions.
* **התזמון לא נכבה.** GitHub מכבה תזמונים אחרי 60 יום בלי פעילות בריפו. הבנייה מפעילה את עצמה מחדש דרך ה-API בכל ריצה מתוזמנת, כך שהעדכונים לא נעצרים בשקט.
* **מה נשאר ידני:** הזנת קודי מבצע חדשים, בקובץ או בשיטס. אליאקספרס לא מפרסמת API לקודי מבצע, אז אתר שמציג רק קודים שבאמת עובדים צריך שמישהו יאשר אותם. זה גם מה שגוגל מצפה לו מאתרי קופונים.
